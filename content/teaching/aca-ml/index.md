Designed and delivered the **Machine Learning** curriculum at the
**Armenian Code Academy (ACA)** across two summer cohorts. Target
audience: industry-bound practitioners with a software background.
Topics:

- Foundations of classical ML (linear models, trees, ensembles)
- Feature engineering, model evaluation, and experiment design
- Deep learning essentials (CNNs, RNNs, Transformers)
- Capstone project track where students shipped end-to-end models

The program emphasizes reproducible, production-ready ML practice.
